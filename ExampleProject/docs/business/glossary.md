# Glossary

- Pokemon, Pokémon: a creature stored in the app, with a name, a type, a level and a description. Not: monster, creature.
- Official pokemon: a pokemon whose name exists in the PokeAPI (exact name, case-insensitive) @NP-006. Opposite: custom pokemon.
- Custom pokemon: a pokemon whose name doesn't exist in the PokeAPI, created from the new pokemon page @NP.
- Type: the element of a pokemon (fire, water, grass...), one per pokemon, chosen from a fixed list. Not: category, kind.
- Level, Lv: a positive integer measuring the strength of a pokemon. Not: rank, power.
- Pokemon list: the main page of the app, listing the pokemons @PL.
- New pokemon page, New pokemon form: the page with the form to add a pokemon @NP.
